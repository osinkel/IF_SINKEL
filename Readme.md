# Тестирование rickandmorty и reqres API
Для тестирования данных сервисов разработана два сценария при помощи Junit, Cucumber и Allure.

## Тест 1
На [сайте](https://rickandmortyapi.com/documentation/#episode-schema) есть документация по АPI по сериалу Рик и Морти.

Логика теста:
1. Найти информацию по персонажу Морти Смит. Выбрать из ответа последний эпизод, где
   появлялся Морти.
2. Получить из списка последнего эпизода последнего персонажа.
3. Получить данные по местонахождению и расе этого персонажа.
4. Проверить, этот персонаж той же расы и находится там же где и Морти? (если раса или
   местоположение не совпадает, то тест успешен).

## Тест 2

На [сайте](https://reqres.in/) есть документация по АPI.

Логика теста:
1. Из файла данного репозитория src/test/resources/json/user.json считывается объект пользователя.
2. У данного объекта пользователя изменяются имя и работа.
3. Посылается запрос на API для создания пользователя
4. Проверить, что полученный ответ имеет валидные данные по значениям имени и работы.

## Запуск
1. Старт теста с очищением target перед стартом из cli.

```bash
mvn clean test
```
либо

```bash
mvn verify
```

2. Запуск теста напрямую из класса CucumberRunnerTest.
3. Запуск из feature файла

## Отчет по тесту

* Создать отчет по выполненному тестированию и локально его сохранить можно с помощью плагина или следующей команды:

```bash
mvn allure:report
```

Отчет будет сохранен по пути target/site/allure-maven-plugin, визуально просмотреть его можно с помощью файла index.html

```bash

├───src
└───target
    ├───allure-results
    ├───classes
    ├───generated-sources
    ├───generated-test-sources
    ├───site
    │   └───allure-maven-plugin
    │       └───index.html
    └───test-classes

```

* Для создания отчета и открытия локального сервера для его просмотра используется следующая команда:

```bash
mvn allure:serve
```
