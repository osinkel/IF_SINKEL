# Тест создания нового бага

Основной функционал программы - тестирование создания задачи в [edujira.ifellow.ru](https://edujira.ifellow.ru/)

## Шаги теста

Каждый шаг теста включает в себя предыдущий.

1. Вход в edujira.ifellow.ru;
2. Перейти в проект 'Test';
3. Проверить общее количество заведенных задач в проекте;
4. Перейти в задачу TestSeleniumATHomework и проверить статус и версию для исправления;
5. Создать новый баг с описанием.

## Запуск теста

Старт теста с очищением target перед стартом.

```bash
mvn clean test
```

Либо есть возможность запустить тест напрямую из класса.

## Отчет по тесту

* Создать отчет по выполненному тестированию и локально его сохранить можно с помощью плагина или следующей команды:

```bash
mvn allure:report
```

Отчет будет сохранен по пути target/site/allure-maven-plugin, визуально просмотреть его можно с помощью файла index.html

```bash

├───src
└───target
    ├───allure-results
    ├───classes
    ├───generated-sources
    ├───generated-test-sources
    ├───site
    │   └───allure-maven-plugin
    │       └───index.html
    └───test-classes

```

* Для создания отчета и открытия локального сервера для его просмотра используется следующая команда:

```bash
mvn allure:serve
```
